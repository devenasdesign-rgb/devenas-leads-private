# Devenas Leads

Личная панель Анастасии для сохранения тёплых запросов на дизайн и сайты.

## Доступ и данные

- Репозиторий должен оставаться **Private**. GitHub Pages не используется.
- Рабочая онлайн-версия рассчитана на закрытое размещение в ChatGPT Sites с доступом только владельцу и входом через ChatGPT.
- Каждый запрос хранится в D1 с идентификатором владельца. API проверяет вход и выдаёт только его записи.
- Страница и ответы сервера содержат `noindex`; это дополнительная настройка, а не замена закрытого доступа.
- Токены и секреты в репозиторий не добавляются.

## Что уже работает

Ручное добавление запроса, ссылка, источник, бюджет, заметки, приоритет, статусы, дата возврата, поиск и фильтры. Автоматический поиск публикаций пока не подключён.

## Структура

- `worker/` — интерфейс и серверные запросы.
- `drizzle/` — схема хранилища.
- `.openai/hosting.json` — настройки закрытого Site и базы D1.
- `scripts/` — сборка и проверка.

`npm run build` собирает Worker без установки зависимостей, `npm run validate` проверяет итоговый модуль. Локальная HTML-версия собирается командой `node scripts/build-local.mjs`, но её данные сохраняются только в одном браузере.
