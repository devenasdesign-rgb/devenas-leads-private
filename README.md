# Devenas Leads

Панель Анастасии для сохранения тёплых запросов на дизайн и сайты.

## Версия для GitHub Pages

Готовая статическая версия находится в `docs/index.html`, а отдельная страница контент-плана — в `docs/content-plan.html`. В меню можно переключаться между ними. В контент-план перенесены идеи с 27 ноября по 11 декабря из черновика от 6 ноября. Площадки Threads, LinkedIn, Instagram, Telegram, Pinterest и Behance открываются отдельными разделами через левое меню или карточки обзора. Четыре идеи ВК скрыты без удаления пользовательских данных. Он позволяет редактировать темы и тексты, выбирать месяц, аккаунт, площадку и статус. В ней есть `<meta name="robots" content="noindex,nofollow,noarchive">`. Не добавляйте запрет чтения в `robots.txt`: поисковому роботу нужно открыть страницу, чтобы увидеть `noindex`.

Чтобы открыть панель по адресу в браузере:

1. В настройках репозитория смените видимость на **Public** (Settings → General → Danger Zone → Change repository visibility).
2. Откройте Settings → Pages.
3. В Build and deployment выберите **Deploy from a branch**, ветку **main**, папку **/docs** и нажмите **Save**.
4. Дождитесь адреса на этой же странице. Обычный адрес проекта будет `https://devenasdesign-rgb.github.io/devenas-leads-private/`, но считайте его рабочим только после успешной публикации.

Публичный репозиторий и сайт доступны любому человеку с ссылкой. `noindex` — указание поисковикам, а не пароль и не гарантия отсутствия URL в поиске. Не публикуйте в коде карточки клиентов, токены и личные данные.

Карточки в версии GitHub Pages остаются в `localStorage` того браузера, где вы их добавили. На телефоне и компьютере будут разные списки. ChatGPT не сможет читать или изменять эти карточки из чата.

## Закрытая серверная версия

Файлы `worker/`, `drizzle/`, `.openai/hosting.json` и `scripts/` относятся к отдельной версии с входом владельца, общей базой D1 и MCP-интерфейсом. GitHub Pages не запускает Worker, базу или MCP. Подключение к ChatGPT заработает только после отдельной публикации этой серверной версии.

## Возможности

Ручное добавление запроса, ссылка, источник, бюджет, заметки, приоритет, статусы, дата возврата, поиск и фильтры. Автоматический поиск публикаций пока не подключён.
