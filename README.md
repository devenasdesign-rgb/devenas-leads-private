# Devenas Leads

Панель Анастасии для тёплых запросов и контент-плана.

## Опубликованная версия

GitHub Pages публикует `docs/index.html` с тёплыми запросами, `docs/content-plan.html` с контент-планом на 30.11–29.12.2026 и `docs/strategy.html` со стратегией и списком визуалов. 69 публикаций нового цикла (Threads, Instagram, LinkedIn, Pinterest, Behance) импортируются в браузер один раз, не перезаписывая пользовательские правки. Прежний план доступен в разделе «Предыдущие черновики», ВК скрыт. Источник нового плана — Notion, но автоматической двусторонней синхронизации нет.

На обеих страницах есть `noindex`. Публичный репозиторий и сайт доступны любому с ссылкой; это не пароль.

Запросы и изменения плана сохраняются в браузере. На телефоне и компьютере будут разные списки, ChatGPT не может их прочитать или изменить из чата. Стратегия — статическая копия страницы Notion, обновления Notion не переносятся автоматически.

## Что уже работает

Ручное добавление запроса, ссылка, источник, бюджет, заметки, приоритет, статусы, дата возврата, поиск и фильтры. В контент-плане доступны месяцы, фильтры, тексты публикаций и статусы. Автоматический поиск публикаций пока не подключён.

## Структура

- `worker/` — исходники интерфейса, контент-плана и серверных запросов.
- `drizzle/` — схема хранилища.
- `.openai/hosting.json` — настройки закрытого Site и базы D1.
- `scripts/` — сборка и проверка.

`node scripts/build-local.mjs` собирает локальные страницы в `docs/`. `npm run build` собирает отдельную серверную версию, `npm run validate` проверяет её. GitHub Pages не запускает Worker, базу D1 или MCP; соединение с ChatGPT требует отдельной публикации серверной версии.
